# Redesign VN Pães - UX/UI
Atividade realizada para a disciplina de User Experience e Usabilidade Web (UNIPÊ).

## Justificativa Técnica
A partir das interfaces iniciais, apliquei os princípios de:
- **Clareza:** Melhoria no contraste e legibilidade nos campos de entrada e textos.
- **Eficiência:** Otimização dos botões de ação (CTA) para facilitar a jornada de compra e finalização do pedido.
- **Estética:** Uso de cores que reforçam a identidade visual da padaria (Aesthetic-Usability Effect).
